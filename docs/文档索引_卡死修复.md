## ⚡ 快速问题排查

### 问题：看到 ⚠️  MQTT loop 耗时过长
```
可能原因：MQTT 连接超时或网络波动
快速解决：
  1. 检查网络连接
  2. Ping MQTT 服务器
  3. 重启 WiFi 或设备
参考文档：快速诊断指南.md
```

### 问题：看到 ⚠️  WebServer 耗时过长
```
可能原因：浏览器连接未关闭
快速解决：
  1. 关闭浏览器配置页面
  2. 重启 WiFi 热点
  3. 重启设备
参考文档：快速诊断指南.md
```

### 问题：看到 ⚠️  LoRa parsePacket 耗时过长
```
可能原因：LoRa 环境干扰
快速解决：
  1. 移动设备位置
  2. 改变天线方向
  3. 远离微波炉等干扰源
参考文档：快速诊断指南.md
```

### 问题：LOOP 总耗时 > 100ms
```
可能原因：多个模块问题
快速解决：
  1. 查看诊断报告
  2. 找到最长的步骤
  3. 对症下药
参考文档：修复说明_卡死诊断系统.md
```
