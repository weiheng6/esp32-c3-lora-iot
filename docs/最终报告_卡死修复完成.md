## 🔧 代码修改总结

### 修改 1：src/mqtt_manager.cpp
```cpp
void MQTTManager::loop() {
  if (mqttClient.connected()) {
    unsigned long mqttLoopStart = millis();
    mqttClient.loop();
    unsigned long mqttLoopDuration = millis() - mqttLoopStart;
    
    if (mqttLoopDuration > 100) {
      Serial.printf("⚠️  MQTT loop 耗时过长：%lu ms\n", mqttLoopDuration);
    }
  }
}
```
**功能**：监测 MQTT 处理时间  
**告警**：超过 100ms

### 修改 4：src/main.cpp（核心修改）
```cpp
void loop() {
  unsigned long loopStart = millis();
  
  // 为 11 个关键步骤分别测时
  unsigned long step1Start = millis();
  checkNetworkConnection();
  unsigned long step1Duration = millis() - step1Start;
  
  // ... 10 个步骤 ...
  
  // 诊断输出
  static unsigned long lastDiagnosticTime = 0;
  unsigned long loopDuration = millis() - loopStart;
  
  if (loopDuration > 100 || (millis() - lastDiagnosticTime > 10000)) {
    lastDiagnosticTime = millis();
    Serial.printf("📊 LOOP 耗时诊断 (总耗时：%lu ms):\n", loopDuration);
    Serial.printf("   ├─ checkNetwork: %lu ms\n", step1Duration);
    // ... 显示 11 个步骤的耗时
  }
}
```

**功能**：完整的 Loop 性能诊断  
**输出**：每 10 秒一次完整报告 + 单次 > 100ms 立即报告
