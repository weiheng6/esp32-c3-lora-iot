# 编译与上传指南

## 快速参考

```bash
# 编译
pio run -e adafruit_qtpy_esp32c3

# 上传
pio run -e adafruit_qtpy_esp32c3 -t upload

# 监视串口（调试日志）
pio device monitor -e adafruit_qtpy_esp32c3
```

## 详细步骤

### 前置条件

✅ 已安装 PlatformIO CLI  
✅ Python 3.7+ 已安装  
✅ ESP32-C3 设备通过 USB 连接到电脑  
✅ 已安装所有必要的库（见 `platformio.ini`）

### 1️⃣ 编译固件

在项目根目录运行：

```bash
cd f:\arduinoWorkspace\lora\platform-esp32-c3
pio run -e adafruit_qtpy_esp32c3
```

**预期输出**：
```
Processing adafruit_qtpy_esp32c3 (platform: espressif32; board: adafruit_qtpy_esp32c3; ...)
...
RAM:   [=         ]  12.6% (used 41228 bytes from 327680 bytes)
Flash: [======    ]  62.7% (used 822060 bytes from 1310720 bytes)
...
========================= [SUCCESS] Took 23.06 seconds =========================
```

**常见问题**:

| 错误 | 原因 | 解决方案 |
|-----|------|---------|
| `error: unknown target` | 环境名错误 | 检查 `platformio.ini` 中的 `[env:...]` 部分 |
| `fatal error: xxx.h not found` | 缺少库 | 运行 `pio lib install` 或检查 `platformio.ini` |
| `memory limit exceeded` | 固件过大 | 检查代码中的大数组或字符串 |

### 2️⃣ 上传到设备

#### 2.1 连接设备

1. 将 ESP32-C3 设备通过 USB 连接到电脑
2. 检查设备是否被识别：

```bash
# Windows
pio device list

# 预期看到类似：
# COM9
# ----
# Hardware ID: USB VID:PID=303A:1001 SER=88:56:A6:6E:49:24
# Description: USB 串行设备 (COM9)
```

#### 2.2 执行上传

```bash
pio run -e adafruit_qtpy_esp32c3 -t upload
```

**预期过程**：
```
Looking for upload port...
Auto-detected: COM9

Uploading .pio\build\adafruit_qtpy_esp32c3\firmware.bin
esptool.py v4.9.0
Serial port COM9
Connecting...
Chip is ESP32-C3 (QFN32) (revision v0.4)
...
Writing at 0x00010000... (100 %)
Wrote 855200 bytes ...
Hard resetting via RTS pin...
================================= [SUCCESS] Took 27.06 seconds =================================
```

#### 2.3 常见上传错误

| 错误 | 原因 | 解决方案 |
|-----|------|---------|
| `Could not open COM9: PermissionError` | 端口被占用 | 关闭监视器或其他串口工具，或重启 VS Code |
| `Failed to connect to ESP32` | USB 连接不稳定 | 重插 USB，或尝试不同的 USB 端口 |
| `Timeout waiting for packet header` | 设备未进入启动模式 | 按住设备上的 BOOT 按钮后松开 |

### 3️⃣ 监视日志输出

编译上传后，打开串口监视器查看设备日志：

```bash
pio device monitor -e adafruit_qtpy_esp32c3 --baud 115200
```

**常用选项**：
```bash
# 指定波特率（默认 115200）
pio device monitor -e adafruit_qtpy_esp32c3 --baud 9600

# 添加时间戳
pio device monitor -e adafruit_qtpy_esp32c3 --time

# 过滤日志（仅显示包含 "⚠️" 的行）
pio device monitor -e adafruit_qtpy_esp32c3 | findstr /C:"⚠️"
```

## 完整工作流程（一次性操作）

```bash
# 1. 进入项目目录
cd f:\arduinoWorkspace\lora\platform-esp32-c3

# 2. 清理旧的构建（可选，但推荐）
pio run -e adafruit_qtpy_esp32c3 -t clean

# 3. 编译
pio run -e adafruit_qtpy_esp32c3

# 4. 如果编译成功，上传
# （假设设备已通过 USB 连接）
pio run -e adafruit_qtpy_esp32c3 -t upload

# 5. 打开监视器观察日志
pio device monitor -e adafruit_qtpy_esp32c3

# 6. 观察至少 30 秒，确保传感器采集和 MQTT 上报正常
```

## 编译配置详解

### platformio.ini 关键部分

```ini
[env:adafruit_qtpy_esp32c3]
platform = espressif32
board = adafruit_qtpy_esp32c3
framework = arduino

# 上传配置
upload_protocol = esptool
upload_speed = 460800
upload_resetmethod = RTS

# 监视配置
monitor_speed = 115200
monitor_filters = esp32_exception_decoder

# 编译优化
build_flags =
    -O2                          # 优化级别 2（平衡速度和大小）
    -DDEBUG_MODE                 # 启用调试日志

# 依赖库
lib_deps =
    PubSubClient @ 2.8.0
    ArduinoJson @ 6.21.2
    LoRa
    Adafruit SHT31
    Preferences
```

### 调整编译选项

**启用详细调试输出**：
```ini
build_flags = -DDEBUG_MODE -DVERBOSE
```

**禁用调试日志（减小固件大小）**：
```ini
build_flags = -DRELEASE_MODE
```

## 增量编译 vs 完整编译

```bash
# 增量编译（只重新编译改变的文件，更快）
pio run -e adafruit_qtpy_esp32c3

# 完整编译（删除所有中间文件，从零开始）
pio run -e adafruit_qtpy_esp32c3 -t clean
pio run -e adafruit_qtpy_esp32c3
```

## 故障排查

### 症状 1: 编译通过但上传失败

**问题**：COM 端口被占用或设备无响应

**解决步骤**：
1. 关闭所有打开的 PlatformIO 监视器窗口
2. 关闭 Arduino IDE 或其他串口工具
3. 重启 VS Code
4. 重新插拔设备 USB
5. 重试上传

### 症状 2: 上传成功但设备无日志输出

**问题**：波特率不匹配或 USB 连接问题

**解决步骤**：
```bash
# 尝试不同的波特率
pio device monitor --baud 9600
pio device monitor --baud 74880   # ESP32 启动日志使用此波特率
pio device monitor --baud 115200  # 标准
```

### 症状 3: 日志乱码

**问题**：波特率或编码问题

**解决步骤**：
```bash
# 检查编译时指定的波特率
grep -i "monitor_speed" platformio.ini

# 确保监视器使用相同波特率
pio device monitor -e adafruit_qtpy_esp32c3 --baud 115200
```

## 批量操作

### 脚本编译与上传（PowerShell）

```powershell
# build_and_upload.ps1
$ProjectPath = "f:\arduinoWorkspace\lora\platform-esp32-c3"
$Env = "adafruit_qtpy_esp32c3"

cd $ProjectPath

# 清理
Write-Host "清理旧构建..." -ForegroundColor Yellow
pio run -e $Env -t clean

# 编译
Write-Host "编译中..." -ForegroundColor Yellow
pio run -e $Env
if ($LASTEXITCODE -ne 0) {
    Write-Host "编译失败！" -ForegroundColor Red
    exit 1
}

# 上传
Write-Host "上传中..." -ForegroundColor Yellow
pio run -e $Env -t upload
if ($LASTEXITCODE -eq 0) {
    Write-Host "✅ 编译和上传成功！" -ForegroundColor Green
} else {
    Write-Host "❌ 上传失败！" -ForegroundColor Red
}
```

使用方法：
```bash
.\build_and_upload.ps1
```

## 进阶：修改代码后的迭代流程

1. **修改源文件**（如 `src/main.cpp`）
2. **立即编译验证**：`pio run -e adafruit_qtpy_esp32c3`
3. **若编译通过**，上传：`pio run -e adafruit_qtpy_esp32c3 -t upload`
4. **打开监视器**：`pio device monitor`
5. **验证日志** 无异常后，关闭监视器
6. **长期运行测试**（见 07_测试验证）
