# 🚀 卡死问题诊断快速指南

## 5 分钟快速开始

### 第 1 步：上传新固件
```bash
cd f:\arduinoWorkspace\lora\platform-esp32-c3
pio run -e adafruit_qtpy_esp32c3 -t upload
```
**等待 5-10 秒，看到 "Successfully uploaded" 即可**

---

### 第 2 步：打开监视器看日志
```bash
pio device monitor -e adafruit_qtpy_esp32c3
```

---

### 第 3 步：认识新的日志格式

#### 正常日志（每秒看到一次）
```
📤 MQTT 上报 - 温度：24.5 °C	湿度：55.0 %RH
```

#### 诊断日志（每 10 秒看到一次）
```
📊 LOOP 耗时诊断 (总耗时：23 ms):
   ├─ checkNetwork: 0 ms
   ├─ WiFi check: 0 ms
   ├─ MQTT connect: 0 ms
   ├─ MQTT loop: 2 ms
   ├─ WebServer: 1 ms
   ├─ LoRa RX: 3 ms
   ├─ LoRa TX: 0 ms
   ├─ Sensor: 8 ms
   ├─ MQTT report: 7 ms
   ├─ Stats: 0 ms
   └─ LoRa discovery: 2 ms
```

#### 警告日志（有问题时立即输出）
```
⚠️  MQTT loop 耗时过长：250 ms
⚠️  WebServer handleClient 耗时过长：800 ms
⚠️  LoRa parsePacket 耗时过长：45 ms
```

## 🎯 根据警告快速判断问题

### 如果看到：⚠️  MQTT loop 耗时过长

**可能原因**：MQTT 连接不稳定或网络问题
```
症状：
  - MQTT 连接卡住
  - 数据无法上报
  - 页面显示离线

快速检查：
  1. Ping 一下 iot.kebaidata.com
  2. 检查 WiFi 是否稳定
  3. 查看 MQTT 服务器是否在线

快速修复：
  - 重启设备
  - 重启 WiFi 路由
  - 重新配置 WiFi
```

---

### 如果看到：⚠️  WebServer 耗时过长

**可能原因**：浏览器/手机连接但未关闭（僵尸连接）
```
症状：
  - 页面半天不加载
  - 设备其他功能也变慢
  - CPU 占用很高

快速检查：
  1. 关闭浏览器的配置页面
  2. 断开手机的配置连接

快速修复：
  - 关闭所有连接
  - 重启 WiFi 热点
  - 重启设备
```

---

### 如果看到：⚠️  LoRa parsePacket 耗时过长

**可能原因**：LoRa 环境干扰
```
症状：
  - LoRa 消息丢失
  - 偶发性能下降
  - 在特定位置变慢

快速检查：
  1. 移动设备位置
  2. 远离微波炉、WiFi 路由
  3. 检查天线连接

快速修复：
  - 改变 LoRa 天线方向
  - 减少 LoRa 发送频率
  - 更换位置测试
```

---

### 如果看到：LOOP 耗时诊断显示某步骤超过 100ms

**可能原因**：该步骤阻塞或出错

**快速查看诊断输出中哪个最长**：
```
📊 LOOP 耗时诊断 (总耗时：250 ms):
   ...
   ├─ MQTT loop: 150 ms  ← 这个最长！
   ...
```

**对应上面的三个情况之一，按照对应方案处理**

## 📊 正常值参考表

| 项目 | 正常值 | 警告值 |
|------|--------|--------|
| 总 LOOP 耗时 | 20-30 ms | > 100 ms |
| MQTT loop | 1-5 ms | > 100 ms |
| WebServer | 1-3 ms | > 50 ms |
| LoRa 接收 | 3-8 ms | > 20 ms |
| LoRa 发送 | 0-2 ms | > 50 ms |
| 传感器读取 | 5-10 ms | > 50 ms |
| MQTT 上报 | 3-10 ms | > 50 ms |

## 🎯 问题定位流程图

```
设备卡死？
  │
  ├─ 看诊断日志有没有警告？
  │  ├─ 有 MQTT loop 警告？
  │  │  └─ 网络问题 → 检查 WiFi 和 MQTT 服务器
  │  │
  │  ├─ 有 WebServer 警告？
  │  │  └─ 僵尸连接 → 关闭所有浏览器连接
  │  │
  │  ├─ 有 LoRa 警告？
  │  │  └─ 环境干扰 → 移动位置或改天线方向
  │  │
  │  └─ 没有警告？
  │     └─ 可能是内存泄漏或其他潜在问题
  │        → 运行 24 小时继续观察
```
