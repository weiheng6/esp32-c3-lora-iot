# 📚 文档导览

> 帮你快速找到需要的文档。

---

## 🎯 我是新手，我应该看什么？

**只需要 3 个文件：**

1. **`QUICKSTART.md`** ⭐⭐⭐ **必读！**
   - 第一次使用？看这个！
   - 5 分钟让设备跑起来
   - 包括：安装工具、上传固件、查看日志

2. **`README.md`** ⭐⭐⭐ **重要！**
   - 怎么用这个设备
   - 怎么远程控制
   - 怎么自动判断并开关
   - 常见问题答疑

3. **`include/config.h`** ⭐⭐ **可能需要改**
   - 改 WiFi 热点名称
   - 改 WiFi 热点密码
   - 改 MQTT 服务器地址（如果需要）

---

## 🧑‍💻 我是开发者，我应该看什么？

**这些文件会对你有帮助：**

1. **`README.md`** — 了解整个项目的功能
2. **`include/`** 目录下的各个 `.h` 文件 — 了解模块的接口
3. **`src/main.cpp`** — 了解主程序怎么工作的
4. **各个模块的 `.cpp` 文件** — 看具体怎么实现的

---

## 📂 各个文件夹的用途

| 文件夹 | 用途 | 新手看吗 |
|--------|------|---------|
| `include/` | 所有模块的"说明书" | 一般不看 |
| `src/` | 所有模块的"实现代码" | 需要改代码时看 |
| `lib/` | 本地库（目前为空） | 不看 |
| `test/` | 单元测试（目前为空） | 不看 |
| `.pio/` | 编译时自动生成的文件 | 不看 |

## 💡 常见场景

### "我想第一次使用这个设备"
→ 看 **`QUICKSTART.md`**

### "我想知道怎么用 MQTT 控制继电器"
→ 看 **`README.md`** 的"远程控制"部分

### "我想改 WiFi 热点名称"
→ 编辑 **`include/config.h`**，找到：
```cpp
const char* AP_SSID = "Scott_Device";  // 改这个
```

### "我想改温度阈值"
→ 发 MQTT 消息（不用改代码），具体看 **`README.md`** 的"自动控制"部分

### "我想给传感器换一个"
→ 编辑 **`src/sensor.cpp`**，改读取逻辑

### "我想添加新功能"
→ 看一下其他模块怎么写的，仿照写新模块就行
