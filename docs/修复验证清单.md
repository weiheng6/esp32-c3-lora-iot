## ⚠️ 如果仍然卡死

### 可能原因 1：固件没有更新成功
- [ ] 检查 VS Code 底部状态栏
- [ ] 重新执行 `pio run -e adafruit_qtpy_esp32c3 -t upload`
- [ ] 确保看到"Successfully uploaded"

### 可能原因 2：修改没有生效
- [ ] 检查 `src/web_server.cpp` 是否包含 `WiFi.scanNetworks(true, false)`
- [ ] 检查 `src/main.cpp` 末尾是否是 `delay(20)` 而不是 `delay(10)`

### 可能原因 3：还有其他阻塞操作
- [ ] 查看日志中是否有其他 delay 很长的操作
- [ ] 检查是否有其他 `WiFi.scan*` 调用
- [ ] 检查是否有其他 I/O 操作（文件、EEPROM 等）
