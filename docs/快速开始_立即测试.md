## 🔧 故障排除

### 问题 1：无法编译
```
解决: 检查 PlatformIO 安装、USB 驱动
命令: pio system prune
```

### 问题 2：无法上传
```
解决: 检查 USB 连接、开发板驱动
命令: pio run -e adafruit_qtpy_esp32c3 -t upload -v (详细模式)
```

### 问题 3：串口无输出
```
解决: 
1. 检查波特率（应该是 115200）
2. 检查 USB 是否真的连接
3. 检查设备驱动是否安装
```

### 问题 4：2小时内冻结
```
这不是故障！而是优化不完整的表现
需要进一步调查以下内容：
- 是否出现了 ⚠️ 慢循环 告警？
- 是否出现了 ❌ I2C/MQTT 失败计数？
- MQTT 连接是否断开？
请保存完整的串口日志供分析
```

## 💡 实用技巧

### Tip 1：长期运行测试
不要让串口监视窗口一直显示，这会拖累系统。建议：
```powershell
# 重定向输出到文件，后台运行
pio device monitor -e adafruit_qtpy_esp32c3 --baud 115200 | Tee-Object -FilePath test_log.txt
```

### Tip 2：断开重连
如果需要停止测试再重新开始：
1. Ctrl+C 停止监视
2. 等待 10 秒，让设备稳定
3. 重新运行 `pio device monitor` 连接

### Tip 3：远程观察
使用 MQTT 客户端（如 MQTT Explorer）：
1. 连接到你的 MQTT 服务器
2. 订阅 `sensor/temperature` 和 `sensor/humidity`
3. 可视化看到每 60 秒的数据上报
