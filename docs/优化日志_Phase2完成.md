## 🎯 下一步计划

### 即将进行的优化

**1. I2C 超时保护** (src/sensor.cpp)
```cpp
Wire.setClockStretchLimit(5000);  // 5ms 最大等待
```
- 目标：将 I2C 读取从 42ms 降低到 <5ms
- 方法：添加超时保护，失败时使用上一个有效值
- 收益：释放 ~37ms CPU 时间

**2. MQTT 缓冲优化** (src/mqtt_manager.cpp)
```cpp
if (buffer_low || signal_weak) {
  // 延迟到下个周期
}
```
- 目标：将 MQTT 发送从 45ms 降低到 <5ms
- 方法：检查缓冲区空间，弱信号时延迟
- 收益：释放 ~40ms CPU 时间

**3. 任务调度优化** (src/main.cpp)
```cpp
vTaskDelay(pdMS_TO_TICKS(20));  // 替代 delay()
```
- 目标：优化 19ms "鬼时间"
- 方法：用 FreeRTOS 延迟函数替代 Arduino delay
- 收益：提高 WiFi 任务响应性
