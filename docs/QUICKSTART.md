# 🚀 快速开始 (5 分钟)

> 新手必读！这个文件告诉你怎么用最快的方式让设备跑起来。

---

## 💻 第 1 步：安装工具（5 分钟）

### Windows 用户：

1. **打开 VS Code**
2. **点击左边的"扩展"图标**（像积木那样的）
3. **搜索 "PlatformIO"**
4. **点击第一个结果，然后点"安装"**
5. **等待 2-3 分钟**，VS Code 会自动重启

完成！

---

## 📁 第 2 步：打开项目

1. **在 VS Code 里，点击"文件" → "打开文件夹"**
2. **选择：`f:\arduinoWorkspace\lora\platform-esp32-c3`**
3. **点击"选择文件夹"**

VS Code 会显示项目的所有文件。

---

## 🔌 第 3 步：连接硬件

**用 USB 线连接 ESP32-C3 到电脑。**

就这样。

---

## ⚙️ 第 4 步：一键编译 & 上传

1. **点击 VS Code 底部的"✓ 编译"按钮**（绿色的对号）
   
   或者按快捷键：**Ctrl + Alt + B**

2. **等待 5-10 秒**，看到这样的输出：
   ```
   Successfully created esp32c3 image.
   ✅ 编译成功！
   ```

3. **点击底部的"➜ 上传"按钮**（绿色的箭头）
   
   或者按快捷键：**Ctrl + Alt + U**

4. **等待 3-5 秒**，看到：
   ```
   Leaving... Hard resetting via RTS pin...
   ✅ 上传成功！
   ```

**设备已经在运行了！** 🎉

---

## 📱 第 5 步：查看日志

1. **点击底部的"🔌 监视"按钮**（蓝色的插头）
   
   或者按快捷键：**Ctrl + Alt + M**

2. **等等... 会看到日志：**
   ```
   ✅ SHT31 传感器初始化成功！
   ✅ WiFi 已连接！
   ✅ MQTT 服务器连接成功！
   ```

**看到这些说明设备在正常工作！** ✨

---

## 📡 第 6 步：配置 WiFi

1. **打开手机，找 WiFi**
2. **找到 `Scott_Device` 这个热点，密码 `88888888`**
3. **连接它**
4. **打开浏览器，输入 `http://192.168.4.1`**
5. **选择你家里的 WiFi，输入密码，点保存**
6. **等 5 秒，设备会重启，自动连接**

完成！以后会自动连接。

## 🆘 出问题了？

### "编译失败"？
- 确保 PlatformIO 已经安装
- 重启 VS Code
- 试试删除 `.pio` 文件夹，再编译一次

### "上传失败"？
- 确保 USB 线连接好了
- 试试换一条 USB 线
- 在 VS Code 底部看看是否显示了 COM 端口（比如 COM3）

### "看不到日志"？
- 确保点了"🔌 监视"按钮
- 确保 USB 线还连着
