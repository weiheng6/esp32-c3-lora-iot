# 🔧 MQTT 故障修复使用指南

## 快速总结

**问题：** 设备运行一段时间后，MQTT 上报自动停止，永久无法恢复  
**原因：** MQTT 连接断开后没有重连机制  
**解决：** 添加自动重连机制，发送失败有日志，内存实时监控

## 📊 新增的日志说明

### 1. MQTT 发送失败提示

```
❌ MQTT 发送失败！连接可能已断开，即将重连...
```

**含义：** 温度或湿度数据没有成功发送到 MQTT，原因可能是：
- MQTT 服务器连接断开
- 网络波动
- 认证信息错误

**自动处理：** 系统会在 5 秒后自动尝试重新连接

---

### 2. MQTT 重连尝试

```
🔄 尝试重新连接 MQTT 服务器...
```

**含义：** 系统检测到 MQTT 已断开，正在尝试重新连接

**频率：** 每 5 秒尝试一次

---

### 3. 网络不可用提示

```
⚠️  网络连接不可用，跳过本次上报
```

**含义：** 虽然需要上报数据，但 WiFi 或 MQTT 未连接，所以跳过

**自动处理：** 等待网络恢复，下一个上报周期会再次尝试

---

### 4. 内存监控信息

```
💾 内存状态 - 可用：268512 字节，使用率：18.0%，警告线：15360 字节
```

**含义：** 
- **可用：268512 字节** - 当前还有多少可用内存
- **使用率：18.0%** - 总内存的使用百分比
- **警告线：15360 字节** - 如果可用内存少于这个值，会自动重启

**频率：** 每 30 秒输出一次

**注意：** 如果使用率接近 100%（比如 90% 以上），说明有内存泄漏，系统会自动重启清理。

## ⚙️ 如何调整修复的参数

### 调整 1：改变重连间隔

如果想加快重连速度，修改 `src/main.cpp` 第 36 行：

```cpp
// 原来：5000ms（5秒）
#define MQTT_RECONNECT_INTERVAL 3000  // 改为 3秒

// 或者更慢：
#define MQTT_RECONNECT_INTERVAL 10000  // 改为 10秒
```

**建议：** 5 秒是比较好的平衡，不要改太小。

### 调整 2：改变内存监控周期

如果想更频繁地监控内存，修改 `src/main.cpp` loop 函数中的：

```cpp
// 原来：30000ms（30秒）
if (currentTime - lastNodeDiscoveryTime >= 15000) {  // 改为每 15 秒

  lastNodeDiscoveryTime = currentTime;
  // ...
}
```

**建议：** 30 秒是足够的，不需要改。

### 调整 3：改变内存警告线

如果设备经常因为内存不足而重启，可以修改 `include/config.h` 中的：

```cpp
// 原来：15KB
```

**建议：** 15KB 是根据 ESP32-C3 的内存计算的，不要随意改。

## 🎓 技术细节（了解修复的原理）

### 为什么会出现 MQTT 上报停止

**原始代码的问题：**

```cpp
// 原来的逻辑（有问题）
if (!mqttManager.isConnected() && WiFi.status() == WL_CONNECTED) {
  mqttManager.connect();  // 每次循环都尝试连接
}
```

**问题分析：**
1. 每次 loop() 都调用 connect()，会频繁创建连接
2. PubSubClient 库会有内部重试逻辑，但这样做没有意义
3. 连接失败时没有任何日志提示
4. 长时间连接断开，用户无法发现

### 修复的原理

**新代码的逻辑：**

```cpp
// 新逻辑（有改进）
if (!mqttManager.isConnected() && WiFi.status() == WL_CONNECTED) {
  if (currentTime - lastMqttConnectAttempt >= MQTT_RECONNECT_INTERVAL) {
    lastMqttConnectAttempt = currentTime;  // 记录尝试时间
    mqttManager.connect();
  }
}
```

**改进点：**
1. 使用时间戳控制重连频率（避免频繁重连）
2. 每 5 秒尝试一次（足够频繁，又不浪费资源）
3. 连接成功后重置计时器（下次断开能立即重连）
4. 发送失败有日志提示（用户能看到）
