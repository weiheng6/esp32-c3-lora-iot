## 🔬 测试 1：基础功能测试

### 目标
验证 MQTT 上报是否正常工作

### 测试步骤

1. **启动系统并观察初始日志**
   ```
   预期：看到以下日志
   ✅ SHT31 传感器初始化成功！
   ✅ WiFi 已连接
   ✅ MQTT 服务器连接成功！
   ✅ 所有模块初始化完成！
   ```

2. **观察传感器采集**
   ```
   预期：每秒看到

   📤 MQTT 上报 - 温度：XX.X °C	湿度：XX.X %RH
   ```

3. **持续观察 5 分钟**
   - ✅ 修复成功：日志连贯无中断

## 🔬 测试 3：MQTT 命令响应测试

### 目标
验证收到 MQTT 命令时系统是否响应迅速

### 前置条件
- 设备已连接到 WiFi 和 MQTT 服务器
- 已安装 MQTT 客户端（如 MQTT Explorer 或 MQTTx）

### 测试步骤

1. **打开 MQTT 客户端并连接**
   - 服务器：`iot.kebaidata.com`
   - 端口：`1883`
   - 用户名：`kbuser`
   - 密码：`kbuserspasswd`

2. **在命令主题订阅响应**
   - 订阅：`esp32/{DEVICE_ID}/response`
   - （DEVICE_ID 是设备的 MAC 地址）

3. **准备发送命令**
   - 主题：`esp32/{DEVICE_ID}/command`
   - 消息：`{"relay": 1}`

4. **发送命令并记录**
   - 记录发送时间
   - 观察监视器日志
   - 记录收到响应时间

5. **观察日志输出**
   ```
   预期：
   📥 收到下行指令：{"relay": 1}
   🔌 继电器控制：开启
   ```

### 评分标准
| 项目 | 得分 |
|------|------|
| 响应时间 < 100ms | +10 分 |
| 日志正确输出 | +10 分 |
| 继电器立即响应 | +10 分 |
| **小计** | **+30 分** |

## 🔬 测试 4：压力测试 - 长时间运行

## 🎯 最简单的验证方法

**只需 3 步**：

1. **上传新固件**
   ```bash
   pio run -e adafruit_qtpy_esp32c3 -t upload
   ```

2. **启动监视器**
   ```bash
   pio device monitor -e adafruit_qtpy_esp32c3
   ```

3. **点击扫描 WiFi**
   - 连接到 192.168.4.1
   - 点击"扫描 WiFi"
   - **看监视器日志是否继续输出**

**结果**：
- ✅ **日志继续输出** → 修复成功！
- ❌ **日志停止 10+ 秒** → 修复失败，需要进一步调查
