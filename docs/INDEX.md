## 📊 关键信息速查

### 硬件规格
| 项目 | 值 |
|------|-----|
| 主控 | ESP32-C3 (160MHz, 320KB RAM) |
| 传感器 | Adafruit SHT31 (I2C) |
| 通信 | WiFi 2.4GHz, MQTT, LoRa 433MHz |
| 继电器 | GPIO 输出控制 |

### 性能目标
| 指标 | 目标值 | 现状 |
|-----|--------|------|
| Loop 周期 | <30ms | 24-25ms ✅ |
| I2C 读取 | <50ms | 40ms ✅ |
| MQTT 上报 | <50ms | 45ms ✅ |
| 运行稳定性 | 无间断重启 | 48h+ ✅ |

### 常用命令

```bash
# 编译
cd f:/arduinoWorkspace/lora/platform-esp32-c3
pio run -e adafruit_qtpy_esp32c3

# 上传
pio run -e adafruit_qtpy_esp32c3 -t upload

# 监视日志
pio device monitor -e adafruit_qtpy_esp32c3

# 清理缓存重新编译
pio run -e adafruit_qtpy_esp32c3 -t clean
pio run -e adafruit_qtpy_esp32c3
```
