## 💡 关键指标速查表

### 应该看到（✅ 正常）

| 指标 | 正常范围 | 说明 |
|-----|--------|------|
| 循环时间 | 25-30 ms | 每个 LOOP 的执行时间 |
| 慢循环 | 0 | 无超过 100ms 的循环 |
| I2C 失败 | 0 | 传感器工作正常 |
| MQTT 失败 | 0 | 网络连接稳定 |

### 不应该看到（❌ 异常）

| 异常 | 意味着 | 处理方式 |
|-----|-------|--------|
| 循环时间 > 100ms | 系统过载 | 检查是否有耗时操作 |
| 慢循环 > 0 | 出现瓶颈 | 查看相应的 ⚠️ 告警 |
| I2C 失败 > 0 | 传感器问题 | 检查 SHT31 连接 |
| MQTT 失败 > 0 | 网络问题 | 检查 WiFi 和 MQTT 服务器 |
