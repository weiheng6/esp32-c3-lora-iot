# 📱 ESP32-C3 智能温湿度控制器

一个简单易用的物联网设备。可以测量温度和湿度，通过 WiFi 连接到云服务器，远程控制继电器（比如电灯、风扇）。

---

## ✨ 这个设备能做什么？

✅ **测量温湿度** — 使用 SHT31 传感器  
✅ **连接 WiFi** — 自动连接你的家庭网络  
✅ **云端控制** — 通过 MQTT 远程接收命令  
✅ **控制继电器** — 可以开关电灯、风扇等设备  
✅ **自动判断** — 根据温湿度自动开关设备  
✅ **Web 配置** — 简单的网页界面配置 WiFi  

---

## � 硬件连接（新手必读）

你需要连接以下器材：

| 器材 | 连接到 ESP32-C3 的哪个引脚 | 说明 |
|------|-----------|------|
| SHT31 温湿度传感器 | GPIO8（SDA）、GPIO9（SCL） | I2C 通讯，两根线 |
| LoRa 无线模块 | GPIO4、5、6、7、10 | 远距离通讯用（可选）|
| 继电器 | GPIO20 | 用来开关电灯等设备 |

**最简单的方案**：只用 SHT31 和继电器，不用 LoRa。

## 💻 如何远程控制？

### 方式 1：用 MQTT 客户端（软件）

下载一个 MQTT 客户端软件（比如 MQTT Explorer 或 MQTTx）。

**连接参数**：
- 服务器：`iot.kebaidata.com`
- 用户名：`kbuser`
- 密码：`kbuserspasswd`
- 端口：`1883`

**开关继电器**：
1. 连接后，在订阅栏输入：`esp32/你的设备ID/response`
2. 在发送栏输入：`esp32/你的设备ID/command`
3. 发送这条消息：`{"relay": 1}` （1 表示开，0 表示关）
4. 继电器会立即响应！

### 方式 2：自己写程序（高级）

可以用任何编程语言（Python、JavaScript 等）连接 MQTT 服务器，发送命令。

## 🎯 自动控制（最实用！）

**场景**：温度超过 28°C 时自动开风扇，温度低于 26°C 时自动关闭。

### 配置方法：

发送这条 MQTT 消息：

```json
{
  "condition": {
    "enabled": true,
    "use_hysteresis": true,
    "temp": {
      "enabled": true,
      "high_threshold": 28.0,
      "low_threshold": 26.0
    }
  }
}
```

就这样！设备会自动：
- 温度 > 28°C → 打开继电器（开风扇）
- 温度 < 26°C → 关闭继电器（关风扇）
- 26-28°C 之间 → 保持当前状态（不频繁切换）

## 🔧 常见问题（小白必读）

### Q: 设备无法连接 WiFi？
**A:** 
1. 检查 WiFi 热点是否打开
2. 检查密码是否正确
3. 重启设备：断电 5 秒再接上电

### Q: 收不到温湿度数据？
**A:**
1. 确认 SHT31 传感器是否正确连接
2. 查看日志里有没有 "✅ SHT31 传感器初始化成功" 这条消息
3. 确认 GPIO8、GPIO9 没有接错

### Q: MQTT 连接失败？
**A:**
1. 确保网络正常（能访问百度首页）
2. 检查用户名和密码是否正确
3. 检查 MQTT 服务器地址：`iot.kebaidata.com`

### Q: 想改 WiFi 热点名称或密码？
**A:** 编辑 `include/config.h` 文件，找到这两行改掉：
```cpp
const char* AP_SSID = "Scott_Device";      // 改这个
const char* AP_PASSWORD = "88888888";      // 改这个
```
然后重新上传固件。

### Q: 想改自动控制的温度阈值？
**A:** 不用改代码，直接用 MQTT 发送配置消息（见上面的"自动控制"部分）。

## 💡 小技巧

### 1. 怎么知道设备的 ID？
开启日志，会看到类似这样的信息：
```
✅ 已生成设备 ID：A1B2C3D4E5F6
```
这个 ID 用来当设备的唯一标识（就像电话号码一样）。

### 2. 多个设备怎么管理？
每个设备的 ID 都不一样，MQTT 消息会自动路由到对应的设备。

### 3. 可以用手机 App 控制吗？
可以的！只要有支持 MQTT 的 App（比如 MQTT Client），用上面的连接参数就行。
