# 📋 使用说明总览

## 只需 3 步，快速上手

### 第 1 步：连接热点 & 配置 WiFi

```
1. 设备重置后（或首次启动）
2. 手机连接热点：Scott_Device （密码：88888888）
3. 浏览器访问：http://192.168.4.1
4. 输入你的 WiFi 名称和密码
5. 点击"保存配置"
```

### 第 2 步：记下设备 IP

```
配置成功页面会显示：
  ✅ 设备内网 IP 地址：192.168.x.x
  
记下这个 IP 地址（或点击链接打开）
等待 30 秒自动重启
```

### 第 3 步：连接同一 WiFi & 访问 Web UI

```
1. 手机断开 Scott_Device 热点
2. 手机连接你刚配置的 WiFi
3. 浏览器打开：http://192.168.x.x（刚才的 IP）
4. ✅ 进入管理界面
```

---

## 🎯 三个关键地址

| 场景 | 地址 | 何时使用 |
|------|------|--------|
| 配置 WiFi | http://192.168.4.1 | 连接热点后的首次配置 |
| 日常管理 | http://192.168.x.x | 连接到 WiFi 后使用 |
| 查询 IP | 路由器管理页面 | 需要找设备 IP 时 |

---

## 🔧 如果无法访问 IP

### 尝试这些方法

1. **确认手机在同一 WiFi**
   ```
   设置 → WiFi → 确保连接的是你配置的网络
   ```

2. **确认 IP 地址正确**
   ```
   登录路由器查看设备列表
   搜索 esp32 相关的设备
   ```

3. **等待 10 秒**
   ```
   Web UI 可能还在启动
   稍等片刻后重新刷新页面
   ```

4. **查看串口日志**
   ```
   串口监视中应该能看到：
   ✅ Web UI 已启动（WiFi 连接后）- 访问地址：http://192.168.1.100
   ```

5. **重新配置**
   ```
   如果还是不行，重置 WiFi 重新来一遍
   ```
