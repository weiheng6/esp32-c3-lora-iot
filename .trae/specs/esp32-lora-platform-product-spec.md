# ESP32-C3 分布式LoRa物联网平台 - 产品规格说明书

## 一、项目愿景与定位

### 1.1 产品定位

打造一个**高可用、易配置、可扩展**的分布式LoRa物联网平台，支持：

- 多节点灵活组网（星型、网状混合拓扑）
- 自动网络拓扑发现与路径选择
- 边缘计算与数据聚合
- 生产/调试双模式切换
- **低功耗智能管理**
- **动态LoRa参数优化**

### 1.2 核心价值

| 价值点 | 说明 |
|--------|------|
| **高可用** | 单点故障不影响整体系统，多路径冗余 |
| **灵活配置** | 所有参数可通过WebUI配置，无需重新编译 |
| **混合传输** | 自动选择最优传输路径（Internet/LoRa） |
| **高效传输** | 生产环境Protobuf压缩，调试环境明文JSON |
| **低功耗** | 多级功耗模式，电池供电场景优化 |
| **自适应** | 动态LoRa参数，适配不同传输场景 |
| **易维护** | 远程诊断、日志查看、批量管理 |

```protobuf
  string device_id = 1;
  int64 command_id = 2;
  CommandType type = 3;
  map<string, string> params = 4;
}

enum CommandType {
  RELAY_CONTROL = 0;
  CONFIG_UPDATE = 1;
  OTA_UPGRADE = 2;
  FACTORY_RESET = 3;
}
```

#### 3.5.5 功耗预算计算

```
日功耗预算 = 活跃时间 × 平均电流 + 睡眠时间 × 睡眠电流

示例配置（温湿度传感器）：
- 每5分钟采集一次，上报一次
- 活跃时间：约500ms @ 80mA
- 睡眠时间：299500ms @ 10μA
- 日活跃次数：288次
- 日功耗 ≈ 288 × 0.5s × 80mA + 86400s × 0.01mA ≈ 11.5mAh
```

### 3.6 动态LoRa参数系统

#### 3.6.1 LoRa参数概述

| 参数 | 范围 | 影响 |
|------|------|------|
| 扩频因子 (SF) | 7-12 | 抗干扰能力/传输距离/传输时间 |
| 带宽 (BW) | 7.8-500kHz | 传输速率/抗干扰能力 |
| 编码率 (CR) | 4/5 - 4/8 | 纠错能力/传输时间 |
| 发射功率 (TX) | 0-22 dBm | 传输距离/功耗 |
| 前导码长度 | 6-255 | 可靠性/传输时间 |

#### 3.6.2 预设传输场景

| 场景 | SF | BW | CR | TX | 适用场景 |
|------|-----|-----|-----|-----|----------|
| 超远距离 | 12 | 125kHz | 4/8 | 22dBm | 农村、郊区 |
| 远距离 | 10 | 125kHz | 4/7 | 20dBm | 工业区 |
| 均衡模式 | 9 | 250kHz | 4/6 | 17dBm | 普通环境 |
| 快速传输 | 7 | 500kHz | 4/5 | 15dBm | 城市、高密度 |
| 低功耗 | 8 | 125kHz | 4/6 | 10dBm | 电池供电 |

#### 3.6.3 动态参数调整算法

```cpp
// 参数调整策略
class LoRaAdaptiveController {
    // 根据信号质量调整
    void adjustByRSSI(int rssi) {
        if (rssi > -80) {
            // 信号强，降低SF，提高速率
            decreaseSF();
            decreaseTXPower();
        } else if (rssi < -120) {
            // 信号弱，提高SF，增加距离
            increaseSF();
            increaseTXPower();
        }
    }
    
    // 根据丢包率调整
    void adjustByPacketLoss(float lossRate) {
        if (lossRate > 0.1) {
            // 丢包严重，增加前导码，提高CR
            increasePreamble();
            increaseCodingRate();
        }
    }
    
    // 根据电池电量调整
    void adjustByBattery(uint8_t level) {
        if (level < 30) {
            // 电量低，降低TX功率
            setTXPower(MIN_TX_POWER);
        }
    }
    
    // 根据传输频率自适应
    void adjustByFrequency(uint32_t reportInterval) {
        if (reportInterval > 3600000) {
            // 上报间隔>1小时，使用低功耗配置
            applyPreset(LOW_POWER_PRESET);
        } else if (reportInterval < 60000) {
            // 上报间隔<1分钟，使用快速传输配置
            applyPreset(FAST_TRANSFER_PRESET);
        }
    }
};
```

#### 3.6.4 参数调整规则

| 当前状态 | 检测指标 | 调整动作 |
|----------|----------|----------|
| 传输慢 | RSSI>-80, SNR>10 | SF↓, BW↑ |
| 丢包多 | 丢包率>10% | 前导码↑, CR↑, TX↑ |
| 距离远 | RSSI<-120 | SF↑, TX↑ |
| 距离近 | RSSI>-70, SNR>15 | SF↓, TX↓, BW↑ |
| 电量低 | 电池<30% | TX↓, SF优化 |
| 干扰大 | SNR<0 | SF↑, BW↓ |
| 延迟高 | 传输时间>2s | SF↓, BW↑ |

#### 3.6.5 自适应传输流程

```
[节点运行中]
      │
      ▼
[收集环境信息]
├─ RSSI (信号强度)
├─ SNR (信噪比)
├─ 丢包率
├─ 电池电量
└─ 当前传输频率
      │
      ▼
[评估传输质量]
├─ 质量优秀 (RSSI>-80, SNR>10, 丢包<5%)
│     └─► 可降低功耗配置
├─ 质量良好 (RSSI>-100, SNR>5, 丢包<10%)
│     └─► 保持当前配置
├─ 质量一般 (RSSI>-120, SNR>0, 丢包<20%)
│     └─► 适当提升配置
└─ 质量差 (其他情况)
      └─► 全面提升配置
      │
      ▼
[应用新配置]
├─ 计算最优参数组合
├─ 与网关协商新参数
└─ 逐步切换避免通信中断
```

## 七、总结

这个项目的核心价值在于：

1. **灵活性**：通过WebUI实现全部参数可配置，适应多种应用场景
2. **高可用**：LoRa自组织网络 + 多路径冗余，确保数据可靠传输
3. **高效率**：Protobuf压缩传输，节省带宽资源
4. **低功耗**：多级功耗模式 + 智能休眠，电池供电无忧
5. **自适应**：动态LoRa参数优化，适配不同传输环境
6. **易运维**：远程诊断、日志查看、批量管理，降低维护成本

从产品角度看，还需要重点关注：
- 设备安全（认证、加密）
- 运维便捷性（批量管理、自动化）
- 可靠性保障（数据完整、故障恢复）
- 用户体验（WebUI交互、云平台易用性）
